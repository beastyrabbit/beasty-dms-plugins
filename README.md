# beastybar

A custom [Quickshell](https://quickshell.outfoxxed.me/) bar for the [niri](https://github.com/YaLTeR/niri) Wayland compositor.

## Modules

- **Workspaces** — clickable workspace indicators synced with niri
- **Active Window** — shows the focused window title
- **Clock** — date and time display
- **System Tray** — XDG system tray support
- **CPU / Memory / Network** — live system resource monitors
- **Audio** — volume control via PipeWire
- **Notifications** — full notification system with popup fly-in/out animations, hover pinning, cascade dismiss, notification panel with app stacking, and persistent storage
- **Overview Button** — niri overview toggle

## Requirements

- [Quickshell](https://quickshell.outfoxxed.me/)
- [niri](https://github.com/YaLTeR/niri) Wayland compositor

## Usage

```bash
quickshell -p bar
```
